# ScarTissue — Drift Patch (Legacy Mirror)

**The main download location is now the
[model artifacts repository](https://huggingface.co/amugoodbad229/scartissue-tinyaya-repair-parameters).**

This dataset repository preserves the original abliteration parameters used to create synthetic
safety drift. The same patch file is available in the model repository. It is an artifact mirror,
not a separate prompt dataset or a hosted drifted model.

Existing files and links are retained for reproducibility. Follow the project reproduction guide
rather than treating the original helper as a validated, reversible model-editing service.
The base model's research-use restrictions still apply.

Judge calibration failed. Harm estimates are exploratory, and these parameters are not a
production safety intervention.
