Try the evidence-to-decision workflow

  1. Load the bundled study or import your own evidence. Check its revision, split and limitations.
  2. Set requirements and evaluate. The illustrative defaults are not safety recommendations.
  3. Compare base and drift, then sparse and global repair. Check harm, over-refusal, utility and repair-selected scalars together, not just one attractive score.
  4. Tighten maximum harm-ASR and evaluate again. This study must still report insufficient evidence: changing a policy cannot repair failed calibration.
  5. Select a prompt and inspect judge disagreement across arms. Open the warnings only if you want to read potentially harmful text.
  6. Read each decision's reasons. Download the record and readable summary from the policy panel; they describe the current policy, not a production release approval.
